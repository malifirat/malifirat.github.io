Coursework

01Vision-Based Floor Inspection Using 2D DFT

Used phone video and MATLAB image processing to inspect carpet for local visual anomalies. Frames were converted to grayscale patches, analyzed with a 2D FFT/fftshift workflow, and compared to a clean reference to build an anomaly heatmap.

MATLAB · Image Processing · 2D DFT · Video Analysis

02Catalyst Warm-Up at Idle

Analyzed open OBD-II data from a Toyota Etios and fit a first-order exponential model to catalyst temperature during idle warm-up. One dataset was used for fitting and a second for validation.

MATLAB · OBD-II Data · First-Order Modeling · Validation

03Automobile Coolant Temperature

A separate thermal-system modeling assignment focused on automobile coolant temperature behavior and used measured vehicle data to compare a simplified thermal model against observed temperature change.

Thermal Modeling · Data Analysis · MATLAB

04Arduino-Based 3D Scanner

A small sensing/instrumentation project using Arduino-based data collection to reconstruct spatial measurements into a simple 3D scan.

Arduino · Sensors · Data Collection · 3D Reconstruction

05Differential-Drive Path Tracking on “Rainbow Road”

Planned a parametric path for a differential-drive robot, converted the path into wheel motion using differential-drive kinematics, and compared encoder behavior against the desired trajectory to study tracking error and wheel slip.

MATLAB · Differential-Drive Kinematics · Encoders · Path Planning

06Catenary (Jungle) Bridge Modeling

Modeled the shape of a hanging bridge/cable system and used optimization to compare predicted geometry against measured behavior.

MATLAB · Gradient Descent · Constrained Optimization · Modeling

07Parallelometer Ultrasonic Angle Instrument

Built an angle-measurement instrument using dual 40 kHz ultrasonic sensors and three-stage band-pass amplification. Time-of-flight data were processed in MATLAB; the instrument measured 14° on a 16° validation setup.

40 kHz Ultrasonic Sensors · Analog Filtering · MATLAB · Instrumentation

08Housing Configuration & Infection Modeling

Used an agent-based SIR-style model and network representations to explore how housing configuration changes disease transmission and peak infection behavior.

MATLAB · Agent-Based Modeling · SIR · Network Graphs

09Mask Effectiveness & Infection Peak Modeling

Extended infection modeling to explore how mask effectiveness changes transmission and the timing/magnitude of the infection peak.

MATLAB · Modeling · Parameter Studies · Data Visualization

10Bottle Resonance

Studied resonant behavior in a bottle/acoustic system by connecting physical parameters to measured frequency response.

Dynamics · Resonance · Experimental Measurement

11Harder Hangman

Built a Python/PyGame Hangman game with a GUI, obscure-word generation, and win/lose states as a programming-focused coursework project.

Python · PyGame · GUI Development · Game Logic

12Penalty Shootout Modeling: Barcelona vs Real Madrid

A probability/modeling project comparing penalty-shootout outcomes for Barcelona and Real Madrid.

Probability · Modeling · Data Analysis
