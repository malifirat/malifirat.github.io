Experiment 01

Vision-Based Floor Inspection Using 2D DFT

Developed a vision-based floor inspection system for a robot vacuum using patch-wise 2D Fourier transforms to detect debris on carpet. Compared frequency-domain texture signatures to a clean reference to generate anomaly heatmaps and inform design choices such as patch size, lighting, and detection thresholds.

Tools: MATLAB, 2D DFT, image processing, video analysis

Experiment 02

Catalyst Warm-Up at Idle: First-Order Thermal Modeling

Modeled automotive catalyst warm-up using a lumped first-order energy balance and validated it against OBD-II temperature data from two idle runs. Estimated time constants and evaluated model limitations through error analysis and comparison across runs.

Tools: Energy balances, first-order systems, data fitting, OBD-II data

Original report ↗

Experiment 03

Automobile Coolant Temperature: Lumped Thermal Modeling

Modeled engine coolant warm-up and post-peak cooling at idle using a lumped first-order energy balance. Fit time constants to OBD-II temperature data and compared radiator-only versus effective-area models to evaluate prediction error and physical assumptions.

Tools: Energy balances, first-order systems, data fitting, OBD-II data

Experiment 04

Arduino-Based 3D Scanner (Pan/Tilt IR Sensing)

Designed and built a rudimentary 3D scanner using a pan–tilt servo mechanism and an IR distance sensor. Calibrated sensor voltage to distance, swept the sensor to collect spatial data, and reconstructed the scanned object as a 3D point cloud in MATLAB.

Tools: Arduino, IR sensing, servos, MATLAB, 3D printing

Experiment 05

Differential-Drive Path Tracking on “Rainbow Road”

Planned and executed a parametric path for a differential-drive robot using tangent and curvature-based kinematics. Derived wheel velocities from path geometry, compared planned and encoder-derived motion, and analyzed discrepancies due to slippage and encoder error.

Tools: MATLAB, robot kinematics, encoders

Experiment 06

Catenary (Jungle) Bridge Modeling via Energy Minimization

Modeled the equilibrium shape of hanging bridges built from rubber bands and strings by minimizing potential energy. Used unconstrained gradient descent for elastic elements and constrained optimization (fmincon) for inextensible strings, and compared predicted geometries to experimental measurements.

Tools: MATLAB, gradient descent, constrained optimization, mechanics

Experiment 07

Parallelometer: Ultrasonic Angle Measurement Instrument

Designed and built a parallelometer using dual 40 kHz ultrasonic sensors to measure the angle between a surface and a reference bar. Implemented analog band-pass filtering, time-of-flight distance calculation, and MATLAB-based signal processing to compute surface angle and evaluate measurement error.

Tools: Ultrasonic sensors, analog filters, MATLAB, instrumentation

Experiment 10

Bottle Resonance: Helmholtz Resonator Modeling

Modeled a bottle as a Helmholtz resonator and compared predicted resonant frequencies to experimental measurements across different fill levels. Derived and linearized the governing equations, analyzed deviations from theory, and discussed limitations of the mass–spring approximation for small cavity volumes.

Tools: Analytical modeling, MATLAB, experimental data analysis
